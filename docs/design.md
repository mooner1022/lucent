# 디자인 언어 — 달빛

**한 줄: 은백의 종이, 남색 잉크, 파스텔 하늘 하나. 그리고 화면이 지금을 안다 — 하늘빛이 종이까지 번진다.**

Lucent는 루시아 한 사람과 나누는 대화 한 화면이다. 그래서 화면은 "루시아가 지금 어떤 상태인가"와 "지금 몇 시인가"를 늘 반영한다.
형태(카드 위계, 별 모양 섹션 제목, 밤 띠 머리말, 묶음 면)는 StarLight의 AI 화면에서 가져왔고, 색은 캐릭터에서 뽑았다.

캐릭터 그림은 **옮기지 않고 인용한다**: 은백 머리카락 → 종이, 남색 한복 깃 → 잉크와 밤, 눈과 술 장식의 하늘빛 → 포인트, 구름 자수의 금사 → 주목, 보름달 → 머리말의 달.
대나무·꽃잎·등불 같은 배경 그림은 쓰지 않는다. 머리말에 그림을 얹으면 글보다 먼저 눈에 들어와 시선이 흩어진다.

## 1. 원칙

1. **장식보다 정보.** 화면에서 가장 눈에 띄는 것은 대화와 승인 카드다. 머리말의 하늘도 장식이 아니라 상태 표시다(6장).
2. **포함은 두 겹까지.** 페이지 → (말풍선·카드·묶음 면·입력창·띠) → 내용. 상자 안에 상자를 넣지 않는다. 안쪽 구분은 가는 선과 간격으로 한다.
3. **곡률은 네 단계, 중간 굵기.** 4 / 8 / 12 / 16dp. 알약 모양(높이의 절반)을 쓰지 않고, 그렇다고 각지게도 두지 않는다. 담긴 것의 곡률은 담은 것의 곡률에서 안쪽 여백을 뺀 값이다.
4. **이미지는 모서리가 하나.** 아바타, 파일 아이콘 자리, 첨부 사진, 미리보기, PDF의 쪽 모두 `radius_image`(12dp). 원형 아바타를 쓰지 않는다.
   첨부 칩 안의 작은 그림(28dp)만은 3번을 따른다: 12dp로 깎으면 원이 되므로, 칩의 곡률에서 안쪽 여백을 뺀 4dp다.
5. **상황에 맞춰 변한다.** 같은 자리에 늘 같은 것을 두지 않는다. 무엇이 보일지는 한 곳(`ChatScene`)에서 정한다(7장).
6. **이모지를 그리지 않는다.** 뜻은 아이콘과 색이 전한다(9장).

## 2. 배색

색의 역할은 넷이다: **종이(바탕), 잉크(글자), 하늘(행동), 금사(루시아가 나를 기다리는 것).**
포인트 컬러는 파스텔 하늘색 하나다. 금사는 승인 대기와 주의에만 쓰고, 실이므로 **면을 칠하지 않는다**(윤곽선·아이콘·글자만).

### 하늘 머리말의 색

머리말 띠는 시각에 따라 네 장면이 있고 각 장면은 위·아래 두 색의 세로 그러데이션이다(`sky_<장면>_top/bottom`).

| 장면 | 시각 | 라이트 | 다크 | 띠 위 글자(라이트 / 다크) |
|---|---|---|---|---|
| 새벽 `DAWN` | 05:00–08:00 | `#BFC6F2` → `#F3D6E3` | `#1A1B44` → `#4A3560` | 남색 / 흰색 |
| 낮 `DAY` | 08:00–17:30 | `#8CC1F3` → `#C4E1FA` | `#173456` → `#2A5B8C` | 남색 / 흰색 |
| 노을 `DUSK` | 17:30–20:00 | `#2B2F73` → `#6F5599` + 지평선 빛 | `#17163F` → `#47305F` | 흰색 / 흰색 |
| 밤 `NIGHT` | 20:00–05:00 | `#111845` → `#2B3C8A` | `#070A20` → `#182159` | 흰색 / 흰색 |

띠 위의 글자색은 **테마가 아니라 띠의 밝기**를 따른다(`band_*` 토큰은 테마에 따라 바뀌지 않는다). 상태 표시줄 아이콘도 같이 바뀐다.
가장 불리한 짝도 4.5를 넘는다: 밝은 띠의 `band_ink_muted` 5.2, 노을 아래쪽의 `band_white_muted` 4.5, 다크 낮 아래쪽 5.2.
장면 사이를 섞는 중간색을 쓰지 않는 것도 그래서다. 경계에서는 띠 전체가 0.9초 동안 넘어간다.

## 3. 곡률

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `radius_xs` | 4dp | 말풍선의 꼬리 모서리, 첨부 칩 안의 작은 그림 |
| `radius_s` | 8dp | 칩(제안, 첨부) |
| `radius_m` | 12dp | 단추, 입력 칸, 상황 자리의 띠, 메뉴, **이미지**(`radius_image`) |
| `radius_l` | 16dp | 말풍선, 카드, 묶음 면, 입력창, 대화상자, 머리말의 아랫모서리 |

가장 낮은 면인 한 줄 말풍선이 42dp라서, 큰 단계를 16으로 두어야 알약(21)이 되지 않고 옆이 곧게 남는다.
입력창(16)의 안쪽 여백은 `space_inset` 4dp라 안쪽 단추가 12가 된다. 머리말 아바타의 고리도 초상(12)과 같은 중심으로 돈다.

## 4. 간격(4pt)

`space_xs 4` 한 묶음 안 / `space_s 8` 요소 사이 / `space_m 12` 묶음 사이 / `space_l 16` 화면 가장자리(`gutter`)·면 안쪽 / `space_xl 24` 섹션 사이.
같은 쪽의 말이 3분 안에 이어지면 한 묶음(묶음 안 4dp, 묶음 사이 12dp). **레이아웃에는 숫자를 적지 않고 `dimens.xml`의 토큰만 쓴다.**

## 5. 글자

Hero 24 bold(빈 화면 인사, 첫 연결) / Title 18 bold(화면·카드 제목) / Section 16 bold / Body 15(대화) / BodyS 14(카드 값, 설정 값) / Label 13 medium(보조 설명, 상황 자리) / Caption 12(시각·출처).
글 파일의 미리보기는 Code 13(고정폭, 대화의 코드 블록과 같은 크기).
글꼴은 Wanted Sans, 코드는 JetBrains Mono. 크기·굵기·색은 `styles.xml`의 `Text.*` 한 벌로만 쓴다.

## 6. 하늘 머리말과 아바타 고리

머리말은 그림이 아니라 **색과 달 하나, 밤의 별 몇 개**다(`ui/sky/SkyView`). 두 가지를 말한다.

**지금 몇 시인가.** 장면이 기기 시각을 따른다(2장의 표).

- **달**은 띠의 끝에 크게(지름 96dp) 걸쳐 있고 위와 끝으로 잘려 나간다. 또렷한 아이콘이 아니라 은은한 빛의 면이다: 어두운 띠에서는
  비치는 정도(불투명도 0.26), 밝은 띠에서는 흰 낮달(0.62). 작고 또렷한 달은 "어두운 테마 전환" 단추로 읽히므로 쓰지 않는다.
  모양은 오늘의 **실제 위상**이고(`Moon.phase`), 그늘진 면도 옅게 보인다.
- **별**은 어두운 띠에서만, 머리말 줄의 글자가 없는 쪽에, 달의 바깥에만 놓인다(상태 표시줄 아이콘 곁에도 두지 않는다).
- **하늘빛이 종이에 번진다.** 띠의 아래쪽 색이 머리말 아래 320dp에 걸쳐 옅게 스민다(`glow`). 대화를 내려 읽는 동안에도 본문이
  낮에는 푸르스름하고 새벽에는 발그레하다. 밝은 띠는 0.6, 어두운 띠는 0.13(밝은 종이 위에서 짙어 보이므로), 어두운 테마는 0.55로 섞는다.

**루시아가 어떤 상태인가.** 기색(`Mood`)이 하늘과 아바타 고리(`PresenceAvatarView`)를 함께 바꾼다.

| 기색 | 언제 | 하늘 | 아바타 고리 |
|---|---|---|---|
| `CALM` | 연결됨, 아무 일 없음 | 맑음 | 없음 |
| `ACTIVE` | 쓰는 중, 진행 안내가 오는 중 | 맑음 | 하늘빛 고리 위로 빛이 돈다 |
| `ATTENTION` | 승인 카드가 답을 기다림 | 달의 둘레에 금빛 달무리가 숨 쉰다 | 금빛 고리가 숨 쉰다 |
| `CONNECTING` | 연결하는 중 | 옅은 안개 | 짧은 빛만 돈다 |
| `OFFLINE` | 끊김, 토큰 문제 | 안개가 끼어 색이 가라앉고 달이 흐려지고 별이 사라진다 | 없음. 초상의 색이 빠진다 |

**머리말은 돌아온 사람에게 인사한다.** 30분 넘게 조용하다 돌아왔거나 대화가 비어 있으면 머리말이 커지며 시간대 인사(아침·낮·저녁·밤)를
큰 글자로 건넨다. 커진 만큼 달도 더 드러난다. 글을 쓰기 시작하거나(키보드), 루시아가 말하기 시작하면 이름 한 줄로 줄어든다.

안개는 띠의 밝기를 바꾸지 않는 색을 섞는다(밝은 띠에는 `sky_veil_light`, 어두운 띠에는 `sky_veil_dark`). 글자색이 흔들리지 않게 하려는 것이다.
움직임은 느리고(초당 12장) 화면에 보이는 동안에만 돈다(앱이 뒤로 가면 멈춘다). 시스템의 "움직임 줄이기"가 켜져 있으면 모두 멈춘다.
설정·연결 화면도 같은 띠를 쓴다(`PageSky`): 달과 색만 있고, 연결이 없으면 같이 안개가 낀다.

## 7. 적응형 동작

대화 화면이 상황에 따라 바꾸는 것은 모두 `ChatScene.of(...)` 하나에서 나온다. 연결 상태·쓰는 중·진행 안내·승인 대기·쓰던 글·스크롤 위치·시각을 넣으면
**기색, 상태 줄, 머리말의 크기(인사), 상황 자리, 입력창 안내, 끝으로 가는 단추**가 나온다(`ChatSceneTest`가 아래 표를 지킨다).

**상태 줄**(머리말 이름 아래 한 줄)은 한 번에 한 가지만 말한다. 앞의 것이 이긴다:
루시아가 하는 일(`note`의 글) → "쓰는 중이에요" → "답을 기다리고 있어요 · N건" → "연결됨 · 집 안/밖". 연결이 없으면 그 이유.

**상황 자리**(입력창 바로 위 한 칸)에는 지금 가장 필요한 것 하나만 놓이고, 없으면 자리째 사라진다.

| 상황 | 상황 자리 | 입력창 |
|---|---|---|
| 연결이 끊김 | 가라앉은 띠: "N초 뒤 다시 시도" + `지금 시도` | 안내 글이 이유를 말한다. 글은 쓸 수 있다 |
| 서버가 잠시 막음 | 같은 띠: "N분 뒤 다시 시도" | 〃 |
| 토큰·주소 문제 | 없음 | 입력창 자리가 "다시 입력" 단추로 바뀐다 |
| 승인 카드가 대기 중이고 화면 밖 | 금사 윤곽선 띠(대기 카드와 같은 말투): "승인 대기 N건 · 제목 · 보기" | "승인하거나 말로 답해 보세요" |
| 승인 카드가 화면에 보임 | 없음(보고 있는 것을 가리키지 않는다) | 〃 |
| 30분 넘게 조용했거나 대화가 비어 있음 | 시간대에 맞춰 권하는 말 칩(하늘 안개 면). 누르면 입력창에 담긴다(바로 보내지 않는다). 머리말도 인사한다 | 평소 |
| 글을 쓰는 중 · 키보드가 올라옴 · 루시아가 일하는 중 · 위로 올려 보는 중 | 권하는 말은 사라지고 머리말이 줄어든다 | |

**더하기 시트.** 입력창의 + 단추는 아래에서 올라오는 시트를 연다(StarLight의 "더하기"와 같은 짜임, `AddSheet`).
위에는 붙일 것(사진·파일 타일), 아래에는 루시아가 일하는 방식을 정하는 행 묶음이 있다. 행은 서버가 알려 준 명령(`commands`: 권한 모드,
주 모델, 그 밖에 데몬이 더하는 것)에서 만들고 지금 값(`current`. 권한 모드: 기본, 주 모델: Opus)을 오른쪽에 보인다. 행을 누르면 값을
고르는 시트가 열린다(`CommandSheet`, 설정 화면의 "일하는 방식"도 같은 시트를 쓴다). 시트를 열 때마다, 바꾼 뒤마다 목록을 다시 읽는다.

| 상황 | 시트가 하는 일 |
|---|---|
| 연결 없음 · 서버가 파일을 받지 않음 | 사진·파일 타일이 흐려지고 이유가 아래에 보인다 |
| 이 토큰이 값을 바꿀 수 없음 · 연결 없음 | 선택지는 보기만 하고(지금 값에만 표시), 이유를 아래에 적는다 |
| 선택지를 누름 | 바로 바꾼다. 서버가 바꿨다고 답한 뒤에야 표시가 옮겨 간다. 오류·시간 초과면 그대로 두고 이유를 붉게 적는다 |
| 서버의 답이 어느 선택지를 가리키는지 불확실(지금 값을 알려 주지 않는 예전 데몬) | 어느 것에도 표시하지 않고 답의 글만 보인다 |
| 주 모델의 선택지 | 별칭을 풀어 쓴다(Fable·Opus·Sonnet·Haiku·기본). 모르는 값은 값 그대로. 아래에 사용량 안내 한 줄 |
| 주 모델을 고름(대화 정리를 기다려 주는 데몬) | 선택지 자리에 물음이 놓인다: "정리하고 바꾸기" / "바로 바꾸기" / 취소. 더 큰 모델로 갈 때만 정리가 주 단추다(지금 값이 기본이면 Sonnet쯤으로 본다) |
| 대화를 정리하는 중 | 고리와 한 줄(보통 20~75초, 끝나면 그 모델로 바꾼다), "그만 기다리기". 데몬이 바쁘거나 연결을 기다리면 그렇다고 적는다. 시트를 닫아도 이어지고, 행의 값이 "바꾸는 중…"이 된다. 대화 입력은 막지 않는다 |
| 정리하지 못함 | 이유와 함께 묻는다: "그래도 바꾸기" / "그만두기" |
| 끝남 | 서버의 글(정리의 결과, 바꾼 결과)을 보이고 선택지로 돌아간다. 시트가 닫혀 있었으면 잠깐 뜨는 안내로 알린다 |

**잠깐 뜨는 안내.** 허브가 알리는 일(서버 오류, 보낼 수 없음, 주 모델을 바꾼 결과)은 화면 위쪽에 카드 하나로 잠깐 뜬다
(StarLight와 같은 PeekAlert, 모양은 `Peeks` 한 곳). 카드는 늘 같은 조용한 면이다: `surface`, 가는 윤곽선, `radius_m`, 얕은 그림자.
무슨 안내인지는 카드의 색이 아니라 아이콘과 머무는 시간이 말한다. 아래에는 입력창이 있어 위(하늘 머리말 자리)에 뜬다.

| 수준 | 아이콘 · 색 | 머무는 시간 | 쓰는 곳 |
|---|---|---|---|
| 알림 | 정보 · `sky_deep` | 3초 | (지금은 없다) |
| 잘 됨 | 확인 · `ok` | 2.5초 | 주 모델을 바꿈, 알림 기록을 지움 |
| 주의 | 주의 · `warn` | 4.5초 | 연결이 없어 보낼 수 없음, 모델이 바뀌지 않음, 정리하지 못해 물음이 기다림, 위치 권한을 거절함 |
| 오류 | 주의 · `error` | 5초 | 서버가 알린 오류 |

**휴대폰 기능(설정).** 루시아에게 내주는 기능(위치, 알림 기록, 알림에 답장)은 설정의 "휴대폰 기능" 묶음에 스위치 줄로 있다
([`phone-tools.md`](phone-tools.md)). 스위치는 "내줄지"이고, 휴대폰 권한은 줄의 설명으로 알린다. 줄은 상황에 따라 바뀐다.

| 상황 | 줄이 보이는 것 |
|---|---|
| 꺼짐 | 무엇을 하는지 한 줄(지금 있는 곳을 알려 줘요 등) |
| 켰는데 휴대폰 권한이 없음 | "위치 권한이 필요해요. 눌러서 허용해요", "알림 접근 허용이 필요해요…"(안드로이드 13부터는 '제한된 설정 허용' 안내까지). 줄을 누르면 권한을 묻거나 시스템 화면을 연다 |
| 대략적인 위치만 허용 | "대략적인 위치만 허용돼 있어요" |
| 켜져 있고 쓴 적이 있음 | 설명 아래에 "마지막 사용: 3분 전" |
| 알림 기록이 꺼져 있음 | 답장 줄은 흐리게, "알림 기록을 켜야 쓸 수 있어요" |
| 답장이 켜져 있음 | "답장 전에 묻기" 줄이 더해진다 |
| 알림 기록이 켜져 있음 | "알림 기록 지우기"(몇 개 있는지) 줄이 더해진다 |
| 토큰에 범위 `app_tools`가 없음 | 묶음 맨 위에 "관리 페이지에서 허용이 필요해요" 줄 |

루시아가 기능을 쓰는 동안 대화 화면의 상태 줄에 무엇을 하는지 보인다("휴대폰 위치를 확인하는 중", 끝나고 4초).

**답장 물음 시트.** 루시아가 알림에 답장하기 전에 뜬다(설정 "답장 전에 묻기"). 머리("답장 보내기") → 어디에("루시아가 카카오톡의
'가족방' 대화에 이렇게 답하려고 해요." 단톡방이면 방 이름, 1:1이면 상대) → 보낼 글(묶음 면, 글 그대로, 고를 수 있다) → "보내기"(주 단추) / "보내지 않기" → "확인하지 않으면
보내지 않아요." 28초 안에 답이 없으면 닫히고 보내지 않는다. 내리거나 닫으면 "보내지 않기"다.

**파일 미리보기 시트.** 대화의 파일(그림, 파일 줄)을 누르면 시트가 뜬다(StarLight의 파일 미리보기와 같은 짜임, `FilePreview`).
머리(이름, 크기·종류) → 내용 → 할 일(공유·저장·다른 앱) 순서이고, 내용이 길면 가운데만 구르고 할 일은 제자리에 있다.
무엇을 어떻게 보일지는 `PreviewKind` 한 곳에서 정한다.

| 파일 | 시트가 보이는 것 |
|---|---|
| 그림(PNG·JPEG·GIF·WebP, 이름으로 알아본 BMP·HEIC·AVIF) | 그림 그대로, 시트 폭에 맞춰(`radius_image`). 작은 그림은 세 배까지만 키워 가운데에 둔다. 긴 그림은 시트 안에서 구른다. 누르면 크게 보는 화면이 열린다 |
| 마크다운(`.md` 등) | 대화의 글과 같은 규칙으로 풀어서. 링크는 주소를 보이고 확인을 받는다. 커스텀 이모지는 그리지 않는다(대화가 아니다) |
| 마크다운 속의 표 | 면도 테두리도 없이 굵은 머리 줄과 줄 사이의 가는 선으로. 좁은 표는 시트 폭을 채우고, 넓은 표는 그 표만 가로로 구른다(한 칸은 240dp까지) |
| 글 파일 중 줄글(`.txt`, 확장자로 알 수 없는 글) | 고정폭으로 글자 그대로, 화면 폭에 맞춰 줄을 꺾는다 |
| 글 파일 중 기록·표·코드(`.log`, `.csv`, `.json`, `.kt` 등) | 줄을 꺾지 않고 가로로 굴려 본다(줄이 곧 뜻이다). 400자가 넘는 줄이 있으면(줄바꿈 없는 JSON 등) 꺾는다. 규칙은 `PreviewText.wraps` |
| 글 파일 공통 | UTF-8이 아니면 한국어 윈도 글자 집합(CP949)으로 읽어 본다. 큰 파일은 앞부분 256 KiB만 보이고 위에 그 사실을 한 줄로 적는다 |
| PDF | 쪽마다 그림으로 그려 세로로 늘어놓는다(보이는 쪽만 그린다. 종이는 흰색, 가는 윤곽선). 크기 옆에 쪽수를 적는다. 200쪽이 넘으면 앞 200쪽만. 쪽을 누르면 그 쪽을 더 촘촘히 그려 크게 보는 화면에 올린다 |
| 받는 중 | 고리(크기를 알면 받은 만큼 찬다)와 한 줄. 할 일 셋은 흐리다. 시트를 닫으면 받기도 그만둔다 |
| 받지 못함 | 이유 한 줄. 잠깐의 일(연결 없음, 서버 오류)이면 그 아래에 `다시 시도`. 서버가 지운 파일(보관 기간이 지남)이면 다시 시도가 없다. 할 일은 흐린 채로 둔다 |
| 글로 읽히지 않거나 그림·PDF를 풀지 못함(깨짐, 암호가 걸린 PDF) | "여기서 보여 드릴 수 없어요" 한 줄. 할 일은 쓸 수 있다 |
| 앱이 보일 수 없는 파일(Office 문서·SVG·압축 파일·그 밖) | 받는 동안만 같은 시트가 뜨고(고리, 닫으면 그만둔다), 다 받으면 다른 앱에 넘기고 시트는 닫힌다. 그사이 다른 화면으로 갔으면 넘기지 않고 안내와 할 일을 남긴다. 받아 둔 것이면 시트 없이 바로 넘긴다 |

**크게 보는 화면.** 시트의 그림이나 PDF의 쪽을 누르면 화면 가득 그 그림 하나가 뜬다(`ImageViewerActivity`). 바탕은 테마와 상관없이
밤의 남색(`viewer_backdrop`)이고 위에 닫기와 이름이 있다. 두 손가락으로 키우고 줄이며 두 번 누르면 확대된다. 그림을 조각내어
보이는 만큼만 제 해상도로 풀므로 긴 화면 갈무리의 잔글씨도 키우면 또렷하다(시트는 화면 폭에 맞춰 줄인 그림이다).
세로로 긴 그림은 폭에 맞춰 맨 위부터 보인다. 움직이는 그림(GIF 등)은 통째로 그리고, 키울 수는 없다.

**이모지·스티커 판.** 글 칸 오른쪽의 이모지 단추는 키보드 자리에 판을 연다(다른 메신저와 같은 자리, `ExpressionPanel`). 판이 열리면 단추는
키보드 아이콘으로 바뀌고, 키보드가 올라오면 판이 닫힌다. 뒤로 가기는 판부터 닫는다. 자세한 것은 `docs/emotes.md`.

| 상황 | 판과 입력창 |
|---|---|
| 이모지·스티커를 다루지 않는 데몬(`welcome.expressions` 없음) | 이모지 단추가 없다. 자동 완성도 없다 |
| 분류가 둘 이상(최근 포함) | 갈래 아래에 분류 칩 줄. 고른 것만 하늘 안개 면 |
| 분류가 하나뿐 | 분류 줄이 없다 |
| 찾기 단추를 누름 | 갈래 전환 자리가 찾는 칸이 되고, 키보드가 함께 떠 있는 동안 격자가 낮아진다 |
| 글 칸에서 `:` 다음에 두 글자 | 입력창 위에 맞는 이모지 칩이 놓인다(첨부 칩과 같은 자리·모양) |
| 등록된 그림이 없음 | 격자 자리에 안내 글 |

**줄이 내용에 따라 달라진다**(`ChatRows`).

| 내용 | 모양 |
|---|---|
| 짧은 말 | 말풍선. 반대쪽에 `bubble_gap`을 비운다 |
| 긴 글(코드·표·제목이 있거나, 목록 3줄 이상, 280자 이상) | 말풍선이 화면 폭을 다 쓴다 |
| 이미지 파일 | 파일 줄이 아니라 이미지 그대로. 누르면 미리보기 시트, 길게 누르면 저장. 자리는 한 변 240dp까지, 가장 작게는 120×80dp(`ImageBox`): 길쭉한 그림(긴 화면 갈무리)은 자리를 채우고 넘치는 쪽을 자르고, 작은 그림은 세 배까지만 키워 자리의 가운데에 둔다 |
| 그 밖의 파일 | 줄 하나: 종류를 알리는 아이콘(그림·PDF·글·코드·표·묶음·그 밖, `FileGlyph`) · 이름 · 크기 · 저장 |
| 말을 길게 누름 | 그 말 곁에 할 일이 뜬다: `복사`(통째로), `글 고르기`(시트에 펼쳐 일부만 고른다). 말풍선 안에서는 글을 고를 수 없다 |
| 스티커가 붙은 말 | 말풍선 아래에 그림 한 장(`sticker_size`). 글이 없으면 그림만. 내 스티커에도 보내는 중·실패 표시와 다시 보내기가 그대로 붙는다 |
| 그릴 수 없는 스티커(목록에 없음, 그림 없음) | 칩 모양의 작은 상자에 `[스티커: 이름]` |
| 글 속의 `:name:` | 그 자리에 커스텀 이모지. 이모지 1~3개뿐인 말은 크게(`emoji_jumbo`). 그릴 수 없으면 글 그대로 |
| 코드 블록 | 면을 칠하지 않는다(말풍선 안의 상자가 되므로). 고정폭 글꼴과 앞의 가는 세로줄로 구분한다(`CodeRuleSpan`). 인용문은 하늘색 세로줄 |
| 잇달아 온 진행 안내 | 한 줄로 합친다. 마지막 것과 "외 N단계"만 보이고 누르면 펼쳐진다. 지금 하는 일이면 별이 깜박인다 |
| 답을 기다리는 카드 | 금사 윤곽선, 내용을 줄이지 않고 다 보인다(사양 12.5) |
| 닫힌 카드 | 결과 한 줄(어조 아이콘 · 결과 문구 · 제목)로 접힌다. 누르면 내용이 펼쳐진다 |

**그 밖.**

| 상황 | 화면이 하는 일 |
|---|---|
| 글 칸에 초점 | 입력창 윤곽선이 하늘색으로 번지듯 켜진다(0.16초. 움직임 줄이기가 켜져 있으면 바로) |
| 말풍선이 머리말 밑이나 입력창 위로 굴러 들어감 | 칼로 자른 듯 끊기지 않고 옅어지며 스러진다(24dp, `EdgeFadeRecyclerView`). 머리말의 하늘빛이 종이에 번지는 것과 같은 결이다. 더 굴릴 것이 없는 쪽(대화의 맨 처음, 맨 끝)은 스러지지 않는다 |
| 화면 맨 아래의 내비게이션 막대 자리 | 종이와 같은 색으로 이어진다. 3버튼 내비게이션에서 시스템이 까는 가림막을 끈다(`enableAppEdgeToEdge`, 모든 화면) |
| 키로 초점이 대화 목록에 옴(키보드·방향키) | 목록에는 초점 표시를 칠하지 않는다(시스템의 기본 표시는 대화 전체를 어둡게 덮는다) |
| 손으로 굴리는 중 | 목록이 줄어들어도(상황 자리가 생김) 끝으로 되돌리지 않는다. 대기 카드에서 벗어나 위를 볼 수 있어야 한다 |
| 보낼 것이 생김 | 보내기 단추가 나타난다. 비어 있으면 자리도 없다(회색 비활성 단추를 두지 않는다) |
| 키보드가 올라옴 | 머리말이 이름 한 줄로 줄어든다. 목록은 끝을 놓치지 않는다 |
| 끝을 보는 중에 새 말 | 그 줄이 살짝 떠오르며 들어온다 |
| 루시아가 쓰는 중 | 말풍선 안에서 별 세 개가 차례로 반짝인다(점이 아니라 앱의 별 모양) |
| 끝에서 한 화면 넘게 올려 보는 중 | 목록 위에 끝으로 가는 화살표 단추가 뜬다. 끝에 닿으면 사라진다 |
| 위로 올려 보는 중에 새 말 | 그 단추가 "새 메시지"가 된다(조금만 올렸어도 뜬다) |
| 글 칸에 그림을 붙여넣음 · 키보드가 그림·GIF를 넣음 | 고른 파일과 같이 첨부 칩이 된다. 글은 글 칸에 그대로 들어간다 |
| 첨부한 것이 그림 | 칩 앞에 그 그림이 작게 보인다. 그 밖의 파일은 종류 아이콘 |
| 다른 앱이 글·파일을 공유함 | 종류를 가리지 않고 받는다. 글은 쓰던 글 뒤에 잇고, 파일은 첨부 칩이 된다 |
| 빈 화면 | 큰 초상과 한 줄. 인사는 커진 머리말이 한다 |
| 처음 연결 | 연결 화면에 초상과 첫 줄이 나오고 뒤로 가기가 없다. 주소를 바꾸러 왔을 때는 반대다 |
| 넓은 화면 | 본문 폭을 640dp로 묶고 가운데에 둔다. 달도 본문 끝을 따라 들어온다 |

## 8. 구성(계층)

```
페이지(background)
 ├─ 하늘 머리말(목록 위에 뜬다): 아바타+고리 · 이름/상태 줄 · 메뉴 · (돌아왔을 때) 인사. 달은 띠의 끝에 걸쳐 있다
 ├─ 하늘빛 번짐(머리말 아래 종이)
 ├─ 대화 목록(머리말 뒤까지 이어진다)
 │    ├─ 말풍선(surface | bubble_user) ─ 글 / 이미지 / 파일 줄(상자 없이)
 │    ├─ 카드(surface + 선 | 금사 선) ─ 머리(아이콘·상태 → 제목) · 필드 · 선 · 본문 · 꼬리말 · 단추
 │    └─ 진행 안내(별 + 글자), 날짜(가는 선 사이의 글자)
 ├─ 상황 자리: 띠 하나 또는 칩 한 줄
 ├─ 첨부 칩(입력창 상자 밖)
 ├─ 입력창(surface + 선): + · 글 칸 · 이모지 단추 · 보내기. 안의 아이콘은 같은 굵기의 선(2dp)이다
 └─ 이모지·스티커 판(키보드 자리, 열렸을 때만): 두 갈래 전환과 찾기 · 분류 칩 · 그림 격자

시트(더하기, 값 고르기): 시트(surface, 위 모서리 radius_l) → 타일 | 행 묶음(surface_alt, radius_m) → 내용
시트(파일 미리보기): 시트 → 머리(이름 · 크기) · 안내 · 내용(그림 | 글과 표 | PDF의 쪽, 면 없이) · 가는 선 · 할 일(글자 단추 셋)
시트(글 고르기): 시트 → 머리 · 글
크게 보는 화면(밤의 남색): 닫기 · 이름 → 그림
```

설정: 페이지 → 섹션 이름(별 + 제목, 페이지 위) → 묶음 면 → 행(가는 선으로 구분). 연결 화면(처음 설정)은 면 없이 섹션 이름 → 입력 칸이다: 서버 주소, 토큰, 푸시 알림. 푸시의 칸 셋은 파일에서 불러왔거나 직접 넣겠다고 했을 때, 넣어 둔 값이 있을 때만 보인다(처음 보는 화면을 길게 만들지 않는다).

## 9. 이모지와 글

앱이 그리는 글(카드, 진행 안내, 상태 줄, 명령 답)에서는 서버가 붙인 이모지를 `Plain.text`로 지운다. 같은 뜻은 어조 아이콘과 색이 전한다. 대화 글은 내용이므로 건드리지 않는다.
**커스텀 이모지와 스티커는 대화의 내용이다**(`docs/app-expressions.md`, `docs/emotes.md`): 루시아가 쓴 글이 실리는 곳(말풍선, 진행 안내, 카드의 본문과 값)에서 `:name:`을 그림으로 그린다. 앱이 정한 글(카드의 머리말·제목·버튼, 상태 줄)에는 그리지 않는다. 분류 칩의 아이콘도 유니코드 이모지가 아니라 목록의 그림이다.
스티커는 사진이 아니라 모양이 있는 그림이므로 "이미지 모서리 하나" 규칙을 적용하지 않고 깎지 않는다.
글은 한국어 해요체 하나. 날짜·시각도 기기 언어와 무관하게 한국어.

## 10. 아바타와 로고

크기는 셋이다: 대화 줄의 아바타 40dp(`avatar_list`, 한 줄짜리 말풍선 42dp보다 조금 낮다), 머리말의 아바타 44dp(`presence_size` 52dp에서 고리 자리 4dp씩을 뺀 것), 큰 초상 96dp(`avatar_hero`).

루시아의 얼굴은 둘 가운데 하나다: **루시아가 스스로 정한 프로필 그림**(사양 8.7, 결정 0060), 그것이 없으면 **앱의 기본 모습**.

- **루시아가 정한 그림**: 데몬이 알려 주면(`welcome.profile`, `profile` 프레임) 앱이 받아 얼굴이 보이는 자리 모두에 쓴다. 머리말의 아바타, 대화 줄과 쓰는 중 줄의 아바타, 빈 화면의 큰 초상, 앱이 직접 띄우는 알림의 큰 아이콘이다.
  - 그림은 늘 정사각형이다. 다른 이미지와 같은 모서리(`radius_image`)로 깎는다. 원으로 자르지 않는다.
  - 새 그림을 다 받을 때까지는 보이던 얼굴을 그대로 둔다(기본 모습이 잠깐 끼어들지 않는다). 머리말의 아바타는 앞의 얼굴 위로 새 얼굴이 스며든다(350ms. 움직임을 끈 기기에서는 바로 바뀐다).
  - 연결이 없어도 마지막으로 받은 그림을 보인다. 끊긴 동안 색이 빠지는 것은 기본 모습과 같다.
  - 루시아가 그림을 없애거나(`avatar: null`), 프로필 기능이 없는 예전 데몬에 붙으면 기본 모습으로 돌아간다.
  - **얼굴을 누르면 프로필 그림을 크게 본다**(머리말, 대화 줄, 쓰는 중 줄, 빈 화면의 큰 초상 모두). 받아 둔 원본을 그림 보는 화면(`ImageViewerActivity`)으로 열고, 정한 그림이 없으면 기본 큰 초상을 연다(`FaceViewer`). 보기만 한다.
  - 받기와 보관은 `ProfileStore`가 한다. 화면은 `hub.profile.face`만 본다(큰 초상의 크기와 아바타의 크기 둘로 줄여 둔 것).
  - 첫 연결 화면의 초상은 아직 연결 전이라 늘 기본 모습이다. 서버의 푸시가 띄우는 알림에는 그림이 실리지 않는다.
- **기본 아바타**: 캐릭터 그림에서 얼굴만 가깝게 잘라 쓴다(`drawable-nodpi/lucia_avatar.webp`, 40dp에서도 얼굴이 읽히게). 머리말과 대화 줄은 `ic_avatar_placeholder.xml`을 거쳐 쓴다.
- **기본 큰 초상**: 빈 화면과 첫 연결 화면은 머리 장식까지 보이게 넓게 자른 그림을 쓴다(`lucia_portrait.webp`, `ic_portrait_placeholder.xml`). 바꿀 때는 그 그림이나 그 파일만 바꾼다.
- **로고(앱 아이콘)**: 아직 자리표시다(`ic_logo_placeholder.xml`, 밤하늘 바탕의 고리). 정해지면 그 파일만 바꾼다.
